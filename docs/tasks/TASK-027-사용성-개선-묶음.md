- [x] B-3 초급 흐름의 중심 생각 단계에서 `구조도 다시 고치기` 버튼으로 구조화 단계로 돌아간다. 작성한 중심 생각은 보존한다. AI 후보 재요청은 열지 않는다.

## 학습 흐름 및 안전 제약
- 해당 단계: 읽기·인출, 정리(저장 전).
- 읽기 중 AI 개입 배제 유지. 이전 단계 이동은 AI 요청을 새로 열지 않는다(`recommendationGate`, 초급 후보 게이트 그대로).
- Retell 중 원문·후보·구조도 가림 유지. 정리 화면에서 Retell로 돌아갈 때 다시 가림을 확인한 뒤에만 Retell 화면을 연다. 가림에 실패하면 이동하지 않는다.
- 원문을 다시 본 뒤 Retell을 고치면 `rechecked=true`로 저장된다(기존 재확인 기록 의미 유지).
- 개인정보·비밀값·실제 학습자 응답을 코드·테스트·문서에 넣지 않는다.
