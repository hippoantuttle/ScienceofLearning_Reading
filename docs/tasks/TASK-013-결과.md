## 상태
- 진행 중. 요청서 `TASK-013-전체-독해흐름-단계적-실사용.md` v1의 전체 기능은 아직 구현·검증되지 않았다.
- 사용자의 순서도, 본인→팀원→참가자 단계, 응답 열람 목표와 실제 글·답안의 필요 범위 AI 전송 방향을 요청서와 변경이력에 기록했다.
- 실제 글 기반 읽기 전 추천의 서버 경로 초안을 추가했다. 별도 환경 변수가 명시적으로 활성화되지 않으면 차단되며, 인증·멤버십·기존 호출 한도를 사용한다. 입력은 글 한 필드로 제한하고 오류 로그에 예외 메시지를 남기지 않는다. 기존 가상 예문 경로는 유지한다.
- 실제 글 본문 미리보기·전송 동의·클라이언트 경로를 연결했다. 본문 영역을 찾지 못한 전체 페이지 대체 추출은 차단하며, 읽기 시작 시 미리보기와 동의를 지우고 지연 응답을 폐기한다. 기본 설정은 비활성이며 본인 시험을 위해 Git 제외 로컬 설정에서만 활성화하고 로컬 Worker를 실행했다. 실제 글 전송·배포·실제 제공자 검증은 하지 않았다. 추천 출력의 형식 검사는 주장·결론 노출 방지를 보장하지 않는다.

## 검증
- 기존 `sidepanel.html`, `sidepanel.js`, 제출 계약, AI 패널과 SQL 정책을 읽어 요청서의 주요 차이를 기록했다.
- 서버 경로 추가 후 `node --test tests/pilot-worker.test.mjs tests/worker.test.mjs` 38개 통과; 공유 한도 및 비활성 사용자 사례 추가 후 `node --test tests/pilot-worker.test.mjs` 16개 통과. 모두 모의 공급자·인증 기반이며 실환경이나 응답의 의미적 적합성을 증명하지 않는다.
- 화면·클라이언트 연결 후 관련 모의 DOM·클라이언트·서버 테스트를 실행했다. 실제 Chrome, 제공자 및 실제 글은 검증하지 않았다.
- 본인 시험 준비: 관련 테스트 31개 통과, 로컬 Worker의 확장 Origin 사전 요청 204 및 미인증 요청 401 확인. 로컬 설정 JavaScript 구문 검사 통과. 실제 로그인과 추천은 사용자의 Chrome 검증 대기.
- 본인 시험 사용자 보고: 실제 글 기반 추천이 정상 작동했다. DeepSeek 플랫폼에서 입력 약 1,000토큰, 출력 약 250토큰을 확인했다. dev의 직접 관찰은 아니며, 해당 수치는 보고된 시험의 대략적인 사용량으로 비용이나 이후 요청의 상한을 보장하지 않는다. 주장·결론 노출 여부와 읽기 시작 후 차단의 실제 Chrome 확인 여부는 별도로 보고받지 않았다.
- 제출 후 피드백·직접 수정·비교의 본인 시험 초안: 저장 및 재조회가 일치한 제출만 패널에서 열고, Worker가 로그인 사용자의 저장된 제출을 조회해 원문과 지정 답안 필드를 AI 제공자에 보낸다. 별도 동의, 회원 확인, 공유 호출 한도, 입력·출력 크기 및 형식 제한을 적용하고 기본 비활성으로 두었다. 본인 시험용 로컬 설정만 활성화했다. 수정과 최초본 비교는 패널 메모리에만 있으며 저장·복습은 미구현이다.
- 관련 테스트 41개 통과. 로컬 Worker에서 사전 요청 204, 미인증 요청 401 확인. 실제 제출 후 피드백의 Chrome·실제 제공자 동작, 의미적 적절성 및 데이터 보관 조건은 미검증이다. 패널을 닫으면 미저장 수정본이 사라진다.
- 사용자 요청으로 개발 중 로컬 전용 Worker의 호출 한도를 해제했다. 인증·활성 회원 확인은 유지하고 원격 주소 요청은 차단한다. 배포용 Worker의 일일 한도는 변경하지 않았다. 로컬 및 배포용 단위 테스트 20개 통과, 로컬 Worker 미인증 요청 401 확인. 실제 AI 호출은 제한 없이 비용이 발생할 수 있다. 로컬 실행 설정 `wrangler.pilot-ai.local.jsonc`는 배포하지 않는다.
- 사용자 보고 `disabled` 오류: 기존 8787 포트를 이전 제출 전용 AI Worker 프로세스가 점유하고 있었고 실제 요청도 그 서버로 향했다. 해당 프로세스는 그대로 두고 개발 서버·Git 제외 로컬 설정을 8793으로 분리했으며 확장의 로컬 host 권한을 추가했다. 해당 서버에 합성 본문과 가짜 토큰을 전송한 결과 `disabled`가 아닌 401을 확인했다. 정상 인증·실제 AI 피드백은 사용자 재검증 대기.
- 사용자의 추가 요청에 따라 로컬 설정에서 읽기 전 추천의 한 시도 내 반복 요청도 허용했다. 동시 요청과 읽기 시작 이후 요청·지연 응답은 계속 차단하며, 원격 서버는 기존 제한을 유지한다. 관련 테스트 29개 통과. 실제 데이터 요청·과금 여부는 사용자 확인 전이다.
- 사용자 보고: 실험 완료 프로세스 전체의 사용량은 입력 약 6,000토큰, 출력 약 600토큰이다. 사용자가 확인한 대략적인 값이며 dev가 플랫폼에서 직접 조회하지 않았다. 이번 보고만으로 피드백 성공 여부나 개별 단계별 사용량, 실제 비용을 단정하지 않는다.
- 사용자 후속 보고: 이번에 목표로 한 기능이 모두 정상 작동했다. 실제 글 추천, 제출 후 AI 피드백과 최초본·수정본 비교를 포함한 본인 시험 성공으로 기록한다. dev가 직접 관찰한 결과는 아니며, 수정본 영구 저장·시간 경과 복습·팀원 열람·참가자 실사용은 이번 검증 대상이 아니다.
- 제공자 약관은 하위 서비스 최종 사용자의 개인정보 처리 규칙이 일반 개인정보처리방침의 범위 밖임을 명시한다. API 입력의 보관·학습 이용·처리 위치는 이 확인만으로 확정할 수 없다. [오픈 플랫폼 약관](https://cdn.deepseek.com/policies/en-UK/deepseek-open-platform-terms-of-service.html)
