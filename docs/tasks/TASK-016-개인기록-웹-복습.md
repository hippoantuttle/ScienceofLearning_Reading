- [ ] 목록에서 복습 예정·완료·중단을 구분하고, 복습 결과를 페이지 새로고침·재로그인 뒤 재조회한다. 기간·횟수·정렬 기준을 명시한다.
- [ ] 본인 자료만 접근하게 하고, 삭제·보관 절차에 복습 기록을 포함한다. 삭제된 원본에 새 복습을 저장하지 못하게 한다.

## 제외 범위
- 자동 이메일·푸시·브라우저 알림, 새 AI 피드백·자동 채점, 다른 관점 글 추천, 적응형 간격·수준 진단.
- 웹에서 최초 독해 수행, 팀원의 참가자 답안 열람, 확장↔웹 자동 로그인.
- 기사 전문·발췌문·AI 피드백의 신규 지속 저장. 복습에 원문이 필요하면 권리·보관·전송 범위를 별도 합의하며 현재 기능에 자동 추가하지 않는다.

## 학습 흐름 및 안전 제약
- 해당 단계: 시간 경과 후 복습. 직접 재구성 중 AI 답·번역·요약·힌트와 과거 답안을 자동 제공하지 않는다.
- 제출 후 피드백 조건: 이번 작업에 AI 호출은 없다. 과거 답안 비교는 복습 결과 저장·재조회 이후에 한다.
- 웹은 원래 기사 탭을 자동 추출·가림하지 않는다. 최초 독해·Retell 가림은 기존 패널 동작을 유지한다.
- 실제 참가자 답안·개인정보·토큰을 공개 저장소·URL·로그에 기록하지 않는다. 합성 데이터로 검증한다.

- AC-05: 합성 기록으로 패널 제출→웹 기록 조회→시간 경과 복습→결과 재조회 전체 경로를 확인한다. 로컬 시계·합성 시각 검증과 실제 경과 시간 검증을 구분한다.
