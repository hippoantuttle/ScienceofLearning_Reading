- [ ] 인증·사용자별 접근 제어, 입력 안전성, 동의·보관/삭제 정책 적용. 관리자/서비스 키는 서버에만. 공개 무인증 저장 API 금지.
- [ ] 네트워크 끊김/401·403/검증 실패/500/응답 유실 처리. 다른 사용자의 응답 조회 차단. 제출 후 피드백/채점 생성 없음.
- [ ] 테스트는 합성 응답과 전용 테스트 저장소에서 수행. 실제 참가자 자료를 테스트에 사용하지 않음. 테스트 데이터 정리와 삭제 확인. 배포는 별도 승인.
