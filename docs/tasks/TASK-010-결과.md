## 단일 가상 글 품질 실험 승인 요청안 — 초안, 실행 승인 아님
- **목적·대상**: 학습자에게 노출하기 전 PM이 가상 글 1건에 대한 용어·배경·유형을 비공개 검토. 모델 후보 ID는 현재 로컬 `server/ai/worker.mjs`의 **`deepseek-flash`**, `thinking.disabled`, `max_tokens=512`. 실제 제공 여부·현재 가격·정확한 배포 모델을 실험 직전 공식 자료로 확인해야 하며, 이 기록만으로 모델·요금 보증 불가.
- **정확한 검토 글**: `server/ai/worker.mjs`의 `callProvider` 사용자 메시지에 하드코딩된 자체 작성 도서관 예문(해당 파일의 `자체 작성 예문:`으로 시작하는 문자열 전부). 공개 결과 문서에 원문을 추가 복제하지 않는다. 현재 v18 화면의 고정 글과는 서로 다른 예문이다. 사용자가 실제 승인할 입력과 정확한 로컬 파일 내용·배포 버전의 동일성을 사전에 확인해야 한다. 실제 기사·학습자 응답·URL·개인정보는 제외하며 중계 요청은 `{}`만 허용한다.
- **단일 실험 인증 후보**: 사용자가 실험 전용 단기 토큰을 비공개로 직접 입력하고 중계는 인증 후 요청을 처리한다. 제공자 키는 사용자만 서버 Secret에 직접 설정하며 값은 공유하거나 확장에 넣지 않는다. 토큰의 발급·유효기간·철회 및 일회성 강제는 아직 미구현·미확인이다. CORS는 인증이 아니다. 이 방식은 14명 사용자별 인증 설계가 아니다.
- **서버 측 1회 제한은 필수 미충족**: 현재 로컬 기록의 공유 Durable Object 상한은 누적 3회이며 실패·timeout도 소모한다. 수동 한 번 실행 지시만으로 서버 1회 한도를 보장하지 않는다. 동일 저장소의 기존 누적값·namespace를 보존하면서 이번 실험에 대한 원자적 1회 예약을 어떻게 강제할지 설계·회귀·로컬 동시성 검증 및 PM 승인 필요. 기존 횟수 초기화·namespace 재생성 금지. 구현·배포는 별도 승인과 요청서 갱신 후에만.

### 실제 연결 최소 승인안 — 제안, 미승인·미구현
1. **입력**: 1차 후보는 사용자가 선택해 확인한 자체 작성 가상 글 1건의 본문만 전송. 최대 길이(문자·바이트·토큰)와 잘림/거절 기준은 PM·사용자가 수치를 확정하기 전 전송 금지. URL·제목·식별자·학습자 MTR/Retell·쿠키·개인정보는 제외. 실제 기사는 별도 저작권·개인정보 검토 및 별도 승인 전 금지. 현재 Worker는 `{}` 외 거부하므로 이 제안은 아직 작동하지 않는다.
2. **고지·동의**: 요청 직전 보낼 내용·제공자/모델·목적·처리/보관·비용·철회 한계를 표시하고 요청마다 명시 동의. 거절·오류 시 전송 없이 빈 틀로 수동 진행. 동의 UI·동작은 미구현.
3. **도메인·인증**: 현재 허용은 `http://127.0.0.1:8787/*`뿐. 후보 중계는 기존 기록상의 `https://reading-prereading-experiment.patrick020308.workers.dev` 단일 origin이나 실제 사용·manifest host 권한 추가는 별도 승인 전 금지. CORS는 인증이 아니다. 사용자별 단기·철회 가능한 자격 증명과 서버 검증을 후보로 설계하되 구체 방식 미결. 공용 실험 ACCESS_TOKEN이나 제공자 키를 확장에 내장하지 않고 제공자 키는 서버 Secret에서만 관리한다.
4. **데이터 처리**: 기존 기록상 API 문맥 캐시는 디스크에 저장될 수 있으나 전체 입력·출력의 보존 기간, 학습 이용, 처리 위치 및 하위 처리자 조건은 미확인. 제공자 공식 API 적용 조건을 재확인하고 미확인 잔여 위험과 승인 여부를 명시하기 전 실제 연결 금지. 로그·관측·오류에 원문·답안·키를 남기지 않는 정책과 검증이 필요하다.
5. **비용·중단**: 제안은 명시 요청 1회, 자동 재시도 0, timeout·실패도 1회로 계수, 서버 측 원자적 횟수 제한. 실제 과금 상한은 미증명이고 내부 예약은 비용 상한이 아니다. 사용자별 허용 비용·가격 변동·동시성·키의 다른 사용을 포함한 제한과 경고/중단 기준을 사용자와 확정한다. 이상·누출·예산 초과 우려 시 신규 요청 차단, 사용자 승인된 경로로 비활성화 후 상태 재조회; 만료나 중단이 진행 중 요청 취소를 보장하지 않는다.
6. **품질 게이트**: 자체 가상 글로 PM이 추천을 비공개 대조해 본문 재진술·주장/결론/근거 관계 누출·근거 없는 일반화·주입에 대한 실패 사례를 평가. 실패 시 표시 차단·수정 후 재검토하며 형식 검증이나 한 프롬프트로 의미적 안전성을 보장하지 않는다. 읽기 시작 후 재요청 차단과 지연 폐기, Retell에서만 가림을 실제 Chrome에서 검증한다. 이후 실제 기사 사용 여부는 별도 결정.
