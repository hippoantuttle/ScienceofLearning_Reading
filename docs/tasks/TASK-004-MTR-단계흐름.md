## 학습 흐름 및 안전 제약
- 해당 단계: 읽기 전 → 읽기·인출 → 제출 후.
- 읽기 중 AI 번역·해석·정답·기사 내용 힌트 제공 금지. Week 1은 모든 AI API·네트워크 분석 제외.
- 제출 후 피드백은 고정 Mock만 허용하며 실제 분석 결과가 아님을 표시.
- 기사 전문·MTR은 세션 메모리만 사용. storage/서버 전송/원문 로그/실제 학습자 응답 커밋 금지.
- 가림은 기억에서 작성하도록 돕는 장치이지 우회 방지 보안 장치가 아님. 기본 안내: '기사 원문이 가려졌습니다. 기억나는 내용을 작성하세요.' 생성 효과나 학습 향상을 보장하는 문구 금지.

## 공통 메시지 및 세션 계약
- 패널→content: {action: "EXTRACT_ARTICLE"}, {action: "TOGGLE_BLUR", enabled: boolean}. SET_BLIND_MODE와 혼용하지 않음.
- 추출 성공: {status:"success", text:string, wordCount:number, charCount:number, fallback:boolean}.
- 가림 성공: {status:"success", enabled:boolean}. 실패 공통: {status:"error", code:string, message:string}.
- 세션 대상 tabId/URL은 패널에서 관리. 활성 탭에 매번 무조건 명령을 보내지 않음. URL 변경/수신자 부재는 재분석 안내.
- 상태 재동기화가 필요하면 GET_STATE 등 추가 계약을 결과/요청 변경 이력에 명시. 기사 내용은 DOM에 textContent로 출력.
