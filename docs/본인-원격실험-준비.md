## 사용자가 먼저 설정할 항목

[Cloudflare Workers & Pages](https://dash.cloudflare.com/)에서 **reading-ai-pilot → Settings → Variables and Secrets → Add**를 선택하고 다음 세 항목의 타입을 **Secret**으로 등록한다. 등록 후에도 현재 AI 스위치는 false로 유지한다. 값은 채팅·문서·Git에 보내지 않는다.

| Secret 이름 | 입력할 값 |
|---|---|
| `DEEPSEEK_API_KEY` | 본인이 보유한 DeepSeek API 키를 직접 입력 |
| `SUPABASE_PUBLISHABLE_KEY` | 이 프로젝트의 기존 publishable 또는 앞서 제공한 anon 공개 키. service_role/secret 키 사용 금지 |
| `PILOT_SELFTEST_USER_ID` | Supabase 프로젝트 **Authentication → Users**에서 본인이 확장 로그인에 쓰는 계정의 User UID. 이메일이 아니라 UUID |

서버는 `SUPABASE_ANON_KEY`라는 기존 Secret 이름도 허용한다. 둘 다 등록할 필요는 없다. 도구는 Secret **이름만** 점검한다. 이름이 있다고 값의 정확성을 검증한 것은 아니다.

초기 읽기 전용 확인에서는 위 Worker의 등록된 Secret 이름 목록이 비어 있었다. 후속 사용자 등록·누락 보완 후 세 필수 Secret의 이름/타입 및 배포 후 보존을 확인했다. 이미 다른 Worker에 등록한 Secret은 이 Worker에 자동 복사되지 않는다. 본인이 직접 등록한 뒤에는 값 대신 「세 항목 등록 완료」만 알려주면 된다.

설정 절차 근거: [Cloudflare Secret 공식 안내](https://developers.cloudflare.com/workers/configuration/secrets/). 이 작업에서 Secret 값은 읽거나 복사하지 않았다.
