# 변경 이력 (설계·결정 변경 기록)

설계·기능·방향이 바뀌면 이 표에 기록한다.
- 코드 변경 → git 커밋이 기록
- "결정" 변경(무엇을 왜 바꿨는가) → 이 문서가 기록

비개발 팀원(근거통합·발표)도 이 표로 변경을 추적한다.

## 작성 규칙

- 각 행: 날짜 / 변경 내용 / 이유 / 관련 근거 / 담당
- "이유"는 왜 바꿨는지를 한 줄로, "근거"는 논문·피드백 등 출처를 남긴다.

| 날짜 | 변경 내용 | 이유 | 관련 근거 | 담당 |
|---|---|---|---|---|
| 2026-11-02 | 저장소 초기 설정(.gitignore·시크릿 규칙·변경이력 문서) | public 저장소의 보안 기반 마련 | — | 김민규 |
