- [x] Google 공개 설정을 빌드에서 명시적으로 켜고 필요한 identity 권한만 포함한다. Google Client Secret·명단·UID·실제 토큰을 클라이언트에 넣지 않는다. 기존 비밀번호/본인 시험 설정과 검토 전용 빌드의 호환성을 유지한다.
- [x] 비공개 회차·초대 이메일 등록, Google 제공자가 검증한 이메일 기반 자동 참여 승인, 5/14명 정원과 승인 회수·기한·본인 소유권을 SQL 초안 및 로컬 PostgreSQL로 검증한다. 화면에서 보낸 이메일/user_metadata만으로 승인하지 않는다.
- [x] AI·제출 Worker의 선택적 회차 제한, 종료 후 새 학습/AI 차단 및 기존 본인 기록 조회 구분, 잘못된 회차·위조·다른 사용자 차단을 검증한다. 기존 본인 모드는 유지한다.
- [x] 5인 배포 후보·Google/Supabase 설정·명단 등록 안내와 사람 QA 체크리스트를 준비한다. 실제 계정/이메일은 보호된 서버 관리 경로에서만 다룬다.

## 학습 흐름 및 안전 제약
- 읽기·구조화·Retell 중 AI 및 과거 답안 조회 차단 유지. 피드백은 저장·재조회 확인과 별도 동의 후 제공.
- Google 로그인은 사용자 버튼에서만 시작한다. Google/Supabase의 인증 화면은 사용자가 직접 진행한다. 인증 성공만으로 기록/모델 접근을 허용하지 않는다.
- 토큰·PKCE 검증값은 메모리에만 유지하고 계정/창 전환 및 늦은 결과가 새 시도/다른 로그인에 적용되지 않게 한다.
