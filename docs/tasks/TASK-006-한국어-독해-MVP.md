## 구현 범위
- [ ] 한국어 독해 중심 명칭·안내로 변경. 영어 예시 어휘 카드를 새 범위의 필수 기능으로 유지하지 않음.
- [ ] 수준 진단·초보/숙련 분기·적응형 로직 없이 숙련자 대상 고정 흐름.
- [ ] 정답·내용 힌트 없이 Main Idea 작성. Text Structure는 단순 select 제출이 아니라 빈 구조도의 정보와 관계를 직접 작성.
- [ ] 예시 빈 구조도는 주장–근거/원인–결과/문제–해결 수동 선택. 기본 예시는 주장–근거. 기사 자동 분석 결과로 표시하지 않음. PM이 위임에 따라 정한 MVP 기본값.
- [ ] 읽기와 Main Idea/Text Structure 단계에서는 원문을 가리지 않음. Retell 진입에서만 가리고 종료/이전 읽기 단계 복귀 시 복원. 원문 재확인 후에는 순수 인출 성공으로 표시하지 않음.
- [ ] 감상·새 어휘·관심 분야 최종 정리는 선택 입력. 필수는 중심 생각·구조도 핵심/보조 정보 및 관계·Retell. 내용 정오는 자동 평가하지 않음.
- [ ] 서버 연동 전에는 로컬 작성 완료 확인만 제공하고 실제 제출·저장 완료로 표시하지 않음. 로컬 흐름 및 AI 추천 개발 이후 서버를 연결하여 실제 제출 구현.
- [ ] 기존 아이콘 재열기 결함은 해소되지 않았음. 분석 성공과 별개로 진단·재검증 필요.

## 학습 흐름 및 안전 제약
- 읽기 중 AI 개입 배제 유지. 빈 틀은 허용하되 기사에서 채운 답안을 제공하지 않음.
- 고정 페이딩은 도움을 수행 점수에 따라 바꾸지 않는다는 뜻까지 확인됨. 회차/단계별 축소 일정은 아직 없음. 일정 없이 처음부터 힌트가 없는 상태를 실제 페이딩이 구현됐다고 부르지 않음.
- 핵심 용어·최소 배경지식은 읽기 전 AI 추천으로 제공. 글의 주장·결론·요약·근거 연결의 답을 미리 제공하지 않음. 읽기·구조화·Retell 중 실시간 AI 도움은 금지.
- 향후 AI 유형 추천도 글 구조 파악을 일부 대신할 수 있으므로, 일반 빈 틀 대비 목적·허용 시점·원문 외부 전송·모델 품질을 별도 검토.
- 초기 단계에서 기사·학습자 입력은 세션 메모리만. 후속 AI 단계에서 기사 전송 범위·고지·제공자 보관 정책을 사전 확정. API 키를 확장에 내장하지 않으며 보호된 중계 방식 검토. 중계 서버는 이후 학습 결과 제출 서버와 목적을 구분. 공개 저장소에 원문/실제 응답/시크릿 포함 금지.
- 가림은 보안 장치가 아니며 학습효과를 보장하지 않음. 학습 종료·오류 시 복원 경로 제공.
