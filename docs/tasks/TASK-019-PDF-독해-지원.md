- 요청자: 사용자

- 검토자: PM / 사용자

## 배경과 목표
- 사용자와 사용 상황: PDF 파일에서도 기존 읽기 준비·직접 구조화·Retell·제출·피드백·수정본 저장을 수행한다.
- 해결할 문제: 현재 웹 DOM 본문 추출과 원문 가림만으로는 PDF를 안정적으로 연결할 수 없다.
- 기대 동작: PDF 선택 → 페이지 범위 선택 → 추출 내용 확인 → 읽기 전 준비 → PDF를 보며 구조화 → 원문을 가린 Retell → 제출·피드백·수정본 저장·재조회.

## 구현 범위
- [ ] 사용자가 선택한 로컬 PDF를 확장 전용 읽기 화면에서 연다. PDF.js 및 필요한 worker·폰트 등 실행 자원을 버전을 고정해 패키지에 포함한다. 원격 코드 로드 없이 manifest/CSP·허용 목록 빌드를 검증한다.
- [ ] 첫 버전은 텍스트가 포함된 PDF를 대상으로 페이지 범위 선택·렌더링·텍스트 추출·사용자 확인을 제공한다. 다단·각주·한글·줄바꿈의 추출 순서와 누락을 확인하며 추출 실패를 정상 연결로 표시하지 않는다.
- [ ] 웹 기사/PDF의 자료 연결·세션 검증·가림/복원을 구분하고, 기존 워크시트·단계·제출·AI 계약은 재사용한다. 연결한 문서·범위가 바뀌면 이전 세션의 결과를 폐기한다.
- [ ] 현재 AI 입력 제한(12,000 UTF-16 코드 단위 및 요청 JSON 50,000바이트)에 맞게 범위를 검증한다. 초과 시 범위 조정을 안내하며 조용한 잘라내기·전체 문서 자동 전송을 하지 않는다.
- [ ] Retell에서는 전용 뷰어의 원문·텍스트층·검색 결과·미리보기를 함께 가린다. 재확인·종료·이탈·연결 종료 때 복원하며 다른 문서나 탭을 조작하지 않는다. 별도로 열린 원본 파일까지 열람을 차단한다고 주장하지 않는다.
- [ ] PDF 파일·본문·로컬 경로·원래 파일명을 자동 영구 저장하지 않는다. AI 이용 시 선택 범위의 추출 텍스트만 명시 동의 후 기존 서버 경로로 전송한다. 저장 제목은 사용자가 확인·수정·제외하고 동의하도록 한다. 페이지 범위는 첫 버전에서 확인한 표시 제목에 포함하는 안으로 구체화한다.
- [ ] 파일 크기·페이지 수·렌더링 메모리·취소·자원 해제와 키보드·확대·좁은 화면을 검증한다. 파일/본문은 세션 메모리에만 두며 종료 후 재선택이 필요할 수 있음을 안내한다.

## 제외 범위
- 스캔 PDF의 OCR, 표·그림의 의미 해석, 암호화 PDF 해제·권한 우회, 원격 PDF URL 자동 가져오기.
- 파일/기사 전문/AI 결과의 신규 지속 저장, 자동 요약·번역·독해 중 힌트, 웹 MVP·복습·참가자 수집.
- Chrome 기본 PDF 뷰어 내부 DOM 주입을 필수 경로로 삼는 구현.

## 학습 흐름 및 안전 제약
- 읽기 전: 최소 어휘·배경만 제공하고 주장·결론을 미리 주지 않는다.
- 읽기·구조화·Retell: AI 요청·지연 결과와 과거 답안 조회 차단을 유지한다. PDF 추출 확인은 학습 시작 전의 자료 확인이며 답안 생성에 사용하지 않는다.
- 제출 후: 최초 제출의 저장·재조회 일치와 별도 동의 이후에만 피드백을 제공한다. 수정본은 기존 명시 저장 절차를 유지한다.
- 실제 PDF·답안·파일명·경로·인증값은 공개 저장소·로그·결과서에 넣지 않는다. 직접 만든 합성 PDF로 검증하고 외부 전송 범위를 안내한다.

## 완료 기준
- AC-01: 텍스트 PDF의 지정 범위만 연결·표시·추출하고 한글·다단·줄바꿈의 확인 경로가 있다. 빈/손상/스캔/암호화/과대 파일을 거짓 성공 없이 안내한다.
- AC-02: 전용 읽기 화면에서 기존 전체 학습·제출·직접 수정·저장·재조회가 동작하며 웹 기사 흐름도 유지된다.
- AC-03: Retell에서 텍스트·검색·미리보기까지 가리고 재확인/종료/이탈 시 복원한다. 잘못된 문서·범위의 결과를 적용하지 않는다.
- AC-04: 읽기 중 AI 요청·지연 결과·과거 답안 조회가 차단된다. 초과 본문을 잘라 보내거나 동의 없이 전송하지 않고 실패 시 작성 입력을 유지한다.
- AC-05: 파일·본문·로컬 경로의 신규 영구 저장·공개 로그가 없고 패키지에 실제 자료·원격 코드가 없다. 실제 설치본의 키보드·화면 폭·문서 전환·자원 해제를 검증한다.
- 검증: 직접 생성한 비민감 PDF fixture, 추출/세션/가림/AI 게이트/빌드 회귀, 실제 Chrome 산출물. 자동·직접 관찰·사용자 보고·미검증을 구분한다.
