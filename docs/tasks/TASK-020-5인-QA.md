# TASK-020 5인 사람 QA

2026-11-10 / 상태: **미실시**. 사용자 결정으로 TASK-017의 남은 실제 Chrome 검증을 이 단계로 옮긴다. 항목을 이관한 것이지 통과한 것이 아니다. 실제 설치/Google 설정·명단·회차·서버 검증이 준비된 뒤 승인된 5인으로 수행한다.

## 대상과 기록

- 대상: 사전 등록된 팀원 5명. 참가자 14명은 아직 시작하지 않는다. 버전/ZIP 해시·브라우저/OS·계정 방식·AI 활성 여부를 고정한다. 첫 후보는 웹 기사 흐름이며 PDF/웹/복습은 포함하지 않는다.
- 담당: 각 사람은 자기 Google 계정으로 로그인하고 자기 자료만 본다. 운영자는 설치·단계·실패 코드 등 최소 결과를 확인한다. 운영자가 다른 사람의 실제 답안을 열람할 권한은 이번에 추가하지 않았다.
- 기록은 승인된 비공개 보관처의 참여 코드로 남긴다. 공개 결과에는 인원별 원문 대신 집계·비식별 오류 유형만 남긴다. Google 이메일/계정 선택 화면·인증 URL·토큰·실제 학습 입력·화면 녹화는 공개 저장소에 넣지 않는다.
- 각 항목은 수행/통과/실패/차단/미수행을 구분한다. 담당자·일시·빌드·문제 번호·재확인 결과를 남긴다. 5명 시작과 5명 전체 완료를 구분한다.

## 통제된 계정·장애 검사

운영자 관리의 합성/승인 테스트 계정으로만 수행한다. 실제 사람의 계정이나 입력을 임의로 만료·변경하지 않는다.

- 미등록 Google 계정·비활성 명단·비활성 회원·다른 회차: 앱 접근/새 저장·AI 거절. 명단이나 다른 사람의 ID는 노출하지 않음.
- 만료 세션: 원래 입력·대기 요청 유지, 같은 Google UID로 재로그인·재시도 가능. 다른 Google 계정에 원래 제출이 옮겨지지 않음.
- 응답 유실·중복 클릭: 저장과 수정본이 중복되지 않으며 실제 재조회 일치 전 완료 표시 없음.
- AI 실패/한도/기간 종료: 이유 안내, 읽기·직접 작성 유지. 기간 종료 이후 새 저장/AI는 거절하고 기존 승인자의 기록 조회는 유지. 실제 모델 호출로 한도를 소진하는 검사는 별도 승인 없이 하지 않음.
- Google 승인 회수: 이미 유효한 토큰이 있어도 이후 API/DB 요청이 차단됨. 사용자 A가 B의 원본·수정본·피드백 sessionId를 바꿔 접근할 수 없음.
- 모델의 읽기 전 결과가 주장·결론을 미리 주지 않는지, 제출 후 피드백이 답안 대신 직접 수정을 돕는지 사람 검토. 형식 검사나 요청 성공만으로 의미 안전성 통과 처리하지 않음. 실제 자료를 공개 기록으로 받지 않음.
