# 작업 요청·결과 보관

PM이 `../templates/작업요청.md`를 복사하여 `TASK-XXX-작업명.md`를 작성한다.
dev는 같은 ID의 `TASK-XXX-결과.md`에 결과를 보고한다.

1. PM이 기존 작업 ID를 확인하여 중복 없는 ID를 부여한다.
2. 사용자와 합의한 범위·권한을 요청서에 적고 dev에게 절대 저장소 경로와 요청서 경로를 보낸다.
3. dev는 중요한 누락·충돌을 확인한 뒤 구현한다.
4. dev가 결과를 보고하면 PM이 실제 변경과 검증 근거를 확인한다.
5. 사용자 확인 없이 main 병합·push하지 않는다.

이 폴더는 공개된다. 실제 참가자 응답·연락처·원본 로그·비밀키는 넣지 않는다.
