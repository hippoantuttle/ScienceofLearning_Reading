## 현재 확인된 차이
- 현재 읽기 준비에 기존 지식 입력란은 있으나 현재 제출 계약에는 포함되지 않는다. 읽기·구조화, Retell, 최종 정리와 제출 경로가 있다.
- 실제 글 기반 추천, 제출·재조회, 제출 후 AI 피드백·직접 수정·메모리 기반 비교는 본인 시험에서 정상 작동했다고 사용자가 보고했다. dev의 Chrome 직접 관찰이나 참가자 실사용 검증은 아니다. 실사용 AI Worker 배포는 별도 확인이 필요하다.
- 수정본은 패널 메모리에만 있다. 누적 학습 기록 웹·수정본 지속 저장·시간 경과 복습·다른 관점 글 제공은 미구현이다.
- 2026-11-10 읽기 전용 DB 구조·정책 확인: 최초 제출과 회원 테이블만 있고 수정본·복습 테이블은 없다. 최초 제출에는 활성 회원 본인 SELECT·INSERT만 허용된다. 글 제목·URL·전문 및 AI 피드백은 현재 저장 필드에 없다. 실제 응답 내용은 조회하지 않았다.
- 현재 데이터베이스 정책은 활성 사용자 본인 자료만 조회한다. 팀원 타인 자료 열람은 구현·검증되지 않았다.
- 사용자는 합성 제출의 저장·재조회 메시지와 중복 처리를 확인했다. 오프라인 재시도와 합성 테스트 행 삭제는 미완료다.
