# 한국어 독해 훈련 확장 — 개발 중

현재 개발 서버 실행은 [로컬 AI 서버 켜기·끄기](docs/로컬서버-실행.md), 최신 구현·작업 순서는 [작업 현황](docs/tasks/README.md)을 따른다. 아래 AI·제출 설명은 초기 MVP 시점 기록이며 현재 TASK-015 상태와 구분한다.

## TASK-017 설치용 빌드

새 설치용 폴더·ZIP 생성과 분리된 검증 프로필 설치는 [확장 빌드·설치](docs/확장-빌드-설치.md)를 따른다. 본인 전용 원격 AI 환경을 배포했고 저장·추천·피드백 흐름의 사용자 정상 보고를 받았다. 최신 상태·시험 기한·보류 사항은 [세션 인계](docs/handoff/2026-11-10-TASK-017-본인시험확인후.md)를 따른다. 전체 실험/참가자 배포 수용은 별도다.

## Chrome 설치와 확인
1. Chrome 116 이상에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**에서 이 저장소 폴더를 선택합니다. 코드가 바뀐 후에는 확장 카드에서 새로고침합니다.
3. 일반 웹 글 탭에서 확장 아이콘을 누른 뒤 **현재 글 연결** → **읽기·구조화 시작**을 선택합니다.
4. 중심 생각과 빈 구조도를 작성하고 Retell로 이동합니다. Retell 진입 시 원문이 가려지며, 읽기로 돌아가거나 최종 확인으로 이동하면 복원을 시도합니다.

## AI 추천 개발 상태
- 읽기 준비 화면의 버튼은 로컬 모의 서버에서 **기사와 무관한 고정 예시**를 가져옵니다. 실제 AI 호출이나 원문 전송은 하지 않습니다. 읽기 시작 후 새 예시 요청을 막습니다.
- `server/ai/relay.cjs`는 인증·요청 크기·빈도 제한을 시험하는 **로컬 전용 모의 서버**입니다. 빈 JSON만 받으며 기사·학습자 응답을 거부합니다. 실제 모델을 호출하지 않으므로 배포용 또는 운영용이 아닙니다.
- Windows CMD에서 저장소 폴더로 이동한 뒤 `set /p READING_LOCAL_TOKEN=Local test token: `으로 다른 곳에서 쓰지 않는 일회용 테스트 문자열을 직접 입력하고 `node server/ai/relay.cjs`로 실행합니다. **입력값은 화면에 그대로 보이며 숨겨지지 않습니다.** API 키를 사용하지 말고 입력 화면이나 테스트 값을 공유하지 마세요. 같은 값을 패널에서 직접 입력합니다. 종료는 실행 중인 CMD에서 Ctrl+C 후, 같은 CMD에서 `set "READING_LOCAL_TOKEN="`을 실행해 환경변수를 지웁니다.
- 실제 모델·전송 범위·비용·보관·중계 배포 및 인증 정책은 승인 후 별도로 정합니다. `.env.example`에는 키 이름만 기재하며 값은 입력하지 않습니다.

## 주의와 복구
- 본 기능은 개발 중이며 모든 사이트에서 정확한 추출·가림이 보장되지 않습니다. 가림은 보안 장치가 아니고 학습효과나 순수 인출을 보장하지 않습니다.
- 가림이 남거나 복원 오류가 표시되면 해당 기사 탭을 새로고침하세요. 패널·페이지 새로고침 또는 닫기로 **작성 내용이 사라질 수 있습니다**.
- 아이콘으로 패널을 재열지 못하는 문제는 미해결입니다. 확장을 껐다 켜는 것은 임시 우회 방법입니다.
- 로컬 작성 완료는 임시 화면 상태이며 **서버에 제출하거나 저장하지 않습니다**. AI 추천과 서버 제출은 아직 제공하지 않습니다.
- 실제 사용자 자료 또는 외부 기사 전문을 테스트 파일, 로그, 공개 저장소에 기록하지 마세요.
