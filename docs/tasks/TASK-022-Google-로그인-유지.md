# [TASK-022] 브라우저 종료 전까지 Google 로그인 유지

## 상태 및 담당
- 상태: 로컬 구현·자동 검증 완료, 사용자 정상 동작 보고. 개별 생명주기 검증 범위는 결과서 참조. 요청자·검토자: 사용자, 구현 담당: Codex. 요청 버전: v2.

## 배경과 목표
- 패널 재열기와 인증 토큰 만료 때 반복 로그인을 줄인다. 사용자는 브라우저 종료 전까지만 유지를 선택했고 계획에 따른 구현을 요청했다.

## 구현 범위
- Google 인증을 확장 서비스워커에서 관리하고 chrome.storage.session에 최소 세션을 보관한다.
- 패널 복원·요청 직전 사용자/참여 권한 확인, 필요 시 Supabase 토큰 회전, 여러 패널 갱신 중복 차단.
- 저장·기록·수정·AI가 최신 인증을 사용하며 로그아웃/계정 변경/늦은 응답을 처리한다.
- 설정 안내·결정 이력·자동 검사·설치 후보를 갱신한다.

## 제외 범위
- 브라우저 재시작 또는 확장 reload/update 뒤 유지, 비밀번호 로그인 유지 확대, 학습 초안 보관.
- DB/OAuth/Worker 실환경 변경·배포·모델 호출·참가자 정보 수집.

## 학습 흐름 및 안전 제약
- 로그인 복원은 AI·저장·과거 기록 조회를 자동 실행하지 않는다. 읽기 중 AI/과거 답안 차단 유지.
- refresh token은 워커와 session 저장소에만 둔다. Google provider token·PKCE verifier·비밀번호·학습 응답은 저장하지 않는다.
- content script/외부 페이지의 인증 메시지와 저장소 접근을 차단한다. 원격 오류/토큰을 화면·로그에 노출하지 않는다.
- 회차 종료와 인증 만료를 구분하고 기존 승인자의 기록 조회 정책을 유지한다.
